## ✅ Изменения

### 1. Зум в сканере КЕ/СН
- Кнопка-цикл **1× → 2× → 3× → 1×** в левом верхнем углу сканера (стиль как у фонарика)
- **Android**: нативный зум камеры (`track.applyConstraints({zoom})`) — если камера его отдаёт; уровень ограничивается возможностями камеры
- **iPhone**: цифровой зум — превью и рамки ШК масштабируются (CSS), детекция и фото-захват работают по обрезанному центру кадра (`drawZoomCrop`)
- При смене цифрового зума декодеры перезапускаются (`restartScannerDecoding`); при нативном — не требуется
- Сброс на 1× при открытии/закрытии сканера
- Работает и в режиме экономии батареи (фото-режим): фото делается с учётом зума

### 2. Вспышка — скрытие при отсутствии поддержки
- При открытии сканера проверяется `track.getCapabilities().torch`
- Если фонарик не поддерживается (iPhone Safari не даёт управление фонариком) — кнопка **скрывается** вместо тоста «Фонарик не поддерживается»
- На Android кнопка работает как раньше

### 3. ШК из галереи для КЕ/СН
- При добавлении фото из галереи (долгое нажатие / левый край ячейки КЕ/СН) фото **автоматически проверяется на штрих-коды**
- Распознавание всех ШК на фото:
  - **Android**: `BarcodeDetector` — все коды сразу
  - **iPhone**: ZXing — полный кадр + 4 тайла 2×2 (уникальные коды, TRY_HARDER)
- Результат:
  - **1 код** → добавляется в отчёт автоматически + тост «ШК распознан: …»
  - **2+ кода** → модалка **«Выберите штрих-код»**: фото + пронумерованные жёлтые рамки с подписями кодов, тап по рамке — код добавляется; кнопки «Ввести вручную» / «Отмена»
  - **0 кодов** → окно ручного ввода номера (как при съёмке сканером)
- Для КЕ действует проверка формата `isKECode` (13/4 цифры), для СН — любой код
- Дубликаты кодов игнорируются; фото добавляется в отчёт в любом случае
- Работает и при добавлении фото через «+» в сетке фото (камера/галерея) для КЕ/СН типов

### 4. Аудит закрытия ресурсов сканера
- Свернув приложение со открытым сканером, камера, декодеры и таймеры полностью останавливаются (`visibilitychange` → `suspendScanner`) — подтверждено
- Исправлено: после сворачивания/разворачивания кнопка фонарика больше не показывает ложное состояние «вкл»
- Исправлено: при закрытии сканера до готовности видео переставал «висеть» таймер ожидания готовности (утечка интервала)
- Добавлена защита от двойного запуска ZXing-цикла декодирования; старый reader сбрасывается перед созданием нового
- Буфер кадра цифрового зума освобождается при закрытии сканера
