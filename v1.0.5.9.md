# v1.0.5.9 — Релиз

Текущая версия: **1.0.5.9** (version.json)

---

## ✅ Изменения (сессия 30.07.2026)

### 1. Редактирование состава оборудования в начатом отчёте
- На странице чек-листа добавлена кнопка «Изменить состав оборудования»
- Модальное окно с +/- счётчиками для каждого типа
- При увеличении количества — добавляются новые секции
- При уменьшении — удаляются только пустые секции; если есть фото — тост-запрет
- Существующие фото переносятся в обновлённые секции (по совпадению id)

### 2. Фото ключей — только в Аптеке
- `klyuchi` удалён из кассовой зоны для ММ, МК, ГМ — остался только в МА
- Подсказка: «Ключи РМК должны быть установлены в задние USB ПК.»

### 3. ZIP-архив — ускорение на Android
- Фото добавляются через `fetch` + `Blob` (нативный парсинг браузера) вместо base64
- Конвертация dataURL → Blob выполняется параллельно (`Promise.all`)

### 4. Обновление с защитой данных
- `performUpdate()`: вместо SW lifecycle — полная очистка кэшей + аннулирование SW + перезагрузка (надёжно на Android)
- `requestPersistentStorage()` в `init()`: запрос persistent storage — очистка кэша браузера больше не трогает IndexedDB и localStorage
- FSA-папка: имя папки сохраняется в `localStorage` (`_fsFolderName`) — при потере дескриптора в настройках показывается подсказка для повторного выбора
- `loadDrafts()`: подсказка, если папка настроена но дескриптор утерян

### 5. КСО без весов — чекбокс внутри секции
- Для секций КСО добавлен чекбокс «КСО без весов»
- При включении скрываются типы фото `ke_vesi` и `sn_vesi` (КЕ весы / СН весы)
- Флаг сохраняется в секции отчёта (`section.noScales`)
